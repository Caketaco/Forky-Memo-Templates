# Forky-Memo-Templates
All 90+ of my job specific memo templates for [Funky Station](https://funkystation.org/)'s rebase, Forky.

⠀
All memo templates have a "flavor quote." This is usually either a pun, reference, quote, or just something I imagine the role saying. If you can think of something more fitting for a role than what I currently have, make a PR/issue.

Command roles are sorted first before others, so, for example, the Research Director is in the Command folder instead of the Science folder.

If something is not in the proper folder, make an issue/PR/ping me on Discord.
